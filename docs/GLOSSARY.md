# Glossary — Knowledge Graph Book

Technical terms used in the book. Vietnamese translations are provided on first occurrence in the text; this glossary serves as a reference.

Last updated: Chapter 1

| Term (English) | Term (Vietnamese) | Definition | First appearance |
|---|---|---|---|
| Graph | Đồ thị | A mathematical structure G = (V, E) consisting of vertices and edges | Ch.1 |
| Directed graph | Đồ thị có hướng | A graph where edges have direction (ordered pairs) | Ch.1 |
| Labeled graph | Đồ thị có nhãn | A graph where nodes and/or edges carry labels | Ch.1 |
| Node / Vertex | Đỉnh / Nút | A fundamental unit of a graph representing an entity | Ch.1 |
| Edge | Cạnh | A connection between two nodes in a graph | Ch.1 |
| Triple | Bộ ba | A statement (subject, predicate, object) representing a directed labeled edge | Ch.1 |
| Entity | Thực thể | A distinct, identifiable object in a knowledge graph | Ch.1 |
| Relation | Quan hệ | A labeled connection between two entities | Ch.1 |
| Data Graph | Đồ thị dữ liệu | A graph of entities and relations without formal semantics | Ch.1 |
| Taxonomy | Phân loại học | A hierarchical classification system using subclass relationships | Ch.1 |
| Ontology | Bản thể học | A formal specification of concepts, relations, and constraints in a domain | Ch.1 |
| Knowledge Graph | Đồ thị tri thức | Data Graph + Semantics + Context (engineering learning model) | Ch.1 |
| Semantics | Ngữ nghĩa | The meaning assigned to data through schema, ontology, and constraints | Ch.1 |
| Context | Ngữ cảnh | Provenance, time, scope, confidence, and source information | Ch.1 |
| Schema | Lược đồ | A structural definition of allowed types, properties, and constraints | Ch.1 |
| Inference | Suy diễn | Deriving new knowledge from existing facts and rules | Ch.1 |
| Validation | Kiểm chứng | Checking whether data satisfies declared constraints | Ch.5 |
| Provenance | Nguồn gốc dữ liệu | Information about the origin, authorship, and derivation of data | Ch.6 |
| IRI | IRI | Internationalized Resource Identifier — a globally unique identifier | Ch.3 |
| RDF | RDF | Resource Description Framework — W3C standard for data graphs | Ch.2 |
| SPARQL | SPARQL | SPARQL Protocol and RDF Query Language | Ch.2 |
| OWL | OWL | Web Ontology Language — W3C standard for formal ontologies | Ch.4 |
| SHACL | SHACL | Shapes Constraint Language — W3C standard for graph validation | Ch.5 |
| Property Graph | Đồ thị thuộc tính | A graph model with typed nodes/edges carrying key-value properties | Ch.2 |
| Reification | Cụ thể hóa | Representing a statement itself as a resource to attach metadata | Ch.3, 6 |
| Entailment | Hệ quả logic | Logical consequence under a given semantics (RDFS, OWL) | Ch.5 |
| Open-world assumption | Giả định thế giới mở | Absence of a statement does not imply its negation | Ch.4 |
| Forward chaining | Lan truyền tiến | Rule application that derives new facts from existing ones | Ch.5 |
| Knowledge Graph Embedding | Nhúng đồ thị tri thức | Mapping entities/relations to continuous vector space for learning | Ch.8 |
| Link prediction | Dự đoán liên kết | Predicting missing edges in a knowledge graph | Ch.8 |
| GraphRAG | GraphRAG | Retrieval-augmented generation enhanced by graph-structured knowledge | Ch.9 |
| Mechanism | Cơ chế | An abstract pattern of inputs, operations, and conditions instantiable across domains | Ch.4, 10 |
