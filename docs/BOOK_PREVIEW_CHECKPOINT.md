## Editorial corrections made (Chapters 1–2)

1. **Turtle example graph-equivalence** — the Turtle in §2.1.5 now includes
   `ex:Vietnam rdf:type ex:Country` and `ex:France rdf:type ex:Country`, matching the
   Python/RDFLib graph exactly; both represent the same 9-triple domain graph.
2. **Graph isomorphism as the general equivalence mechanism** — §2.1.5 explains that
   raw triple-set equality happens to work only because the example has no blank
   nodes, and that isomorphism (blank-node renaming) is the correct general concept
   (`rdflib.compare` mentioned in the lab companion, concept in the book).
3. **IRI wording** — IRI is taught as a *globally scoped identifier mechanism*; the
   text states explicitly that the same IRI does not prove shared real-world identity
   semantics and different IRIs do not prove different entities; bridges to Chapter 3.
4. **Blank nodes** — expanded: resource without an IRI, serialization labels are local
   artifacts, existential interpretation; kept intuitive, formal semantics deferred.
5. **SPARQL triple-pattern positions** — corrected to the RDF 1.1 position
   constraints (predicate always IRI; subject never literal; object any term).
6. **SPARQL BGP contract** — `docs/CHAPTER02_SEMANTIC_CONTRACTS.md` no longer says
   "subgraph isomorphism"; it now uses SPARQL 1.1-faithful language (solution
   mappings / pattern instances whose instantiated BGP is a subgraph of the active
   graph).
7. **Source-ID consistency** — one canonical ID per source across manuscript, plan,
   contracts, and code (`R11-05` Turtle, `TOOL-01` RDFLib, `N4J-03/05/06` Neo4j, ...);
   mapping to bibliography keys in `docs/CITATION_MAP.md`.
8. **Wrapper regression** — leaked closing tag removed from
   `docs/CHAPTER02_RDF_CHECKPOINT.md` (and 11 other files); the integrity gate now
   scans the full working tree, not only git-tracked files, so newly generated
   Markdown cannot bypass it (negative-tested).
9. **Print-safety pass** — emoji that no installed font covers (📌 ✅ 📖 🚧) replaced
   with print-safe markers (⚑, plain text); ★/⚠/ render via a DejaVu Sans glyph
   fallback; `--number-sections` removed (manuscript carries its own numbering);
   Chapter 1's layer diagram redesigned landscape so it fits the page; print PDF uses
   hidelinks + monochrome code, screen PDF keeps colored clickable links.

## Known layout issues

- Code blocks are monochrome in print by design; in code comments, precomposed
  Vietnamese glyphs fall back to DejaVu Sans (no installed mono font covers them),
  which is visually near-identical at body size.
- Figures are high-resolution PNG (3×), not vector, because no SVG→PDF converter
  (inkscape/rsvg-convert/ImageMagick) is installed; acceptable for print at this
  resolution, vectorizable later.
- The build uses **LuaLaTeX** instead of the preferred XeLaTeX: xelatex is not
  installed and sudo is unavailable. LuaLaTeX + fontspec satisfies the same print
  profile. `scripts/setup_tex_user_tree.sh` reproduces the user-tree TeX packages
  (luaotfload, lualibs, lua-uni-algos, lualatex-math, luatexbase, ctablestack,
  selnolig) that the distro TeX Live lacks.
- Final bibliography page is mostly empty (normal end-of-book pagination).
