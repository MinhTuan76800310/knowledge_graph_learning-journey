## What this source establishes for Ch4
A Java OWL 2 EL classifier implementing a polynomial-time goal-directed consequence-based procedure; usable as CLI, OWL API library, and Protege plugin. Demonstrates that EL's restricted grammar buys scalable, complete classification - the ELK-vs-HermiT expressivity/complexity contrast.

## Safe simplifications
Citing ELK as a production OWL 2 EL classifier is safe.

## Dangerous simplifications / limits
Do not claim ELK handles full OWL 2 DL; it targets the EL profile (plus limited extensions).
