# R11-02: RDF 1.1 Concepts and Abstract Syntax

- **Canonical URL:** https://www.w3.org/TR/rdf11-concepts/
- **Status:** W3C Recommendation (2014-02-25)
- **Fetched:** 2026-08-25, HTTP 200
- **Used in:** Chapters 2, 3

## Key Points

- Defines the RDF abstract data model: triples (subject, predicate, object).
- Subject is IRI or blank node; predicate is IRI; object is IRI, blank node, or literal.
- An RDF graph is a set of triples.
- Introduces IRIs as the universal identifier mechanism.
- Literals have lexical form + datatype IRI (+ optional language tag).
- Blank nodes are existential variables with local scope.

## Semantic Contract for Chapter 1

- A triple is an *assertion* within the graph that contains it.
- The spec does not define "fact" vs "claim" — that distinction is an application-level epistemic policy.
- Reification (Section 3.7) allows stating propositions about triples without asserting them.

## Chapter 3 Findings — RDF Datasets and Named Graphs (fetched 2026-08-25)

- §4 (normative): "An RDF dataset is a collection of RDF graphs, and comprises:
  Exactly one default graph ... Zero or more named graphs. Each named graph is
  a pair consisting of an IRI or a blank node (the graph name), and an RDF
  graph. Graph names are unique within an RDF dataset."
- §4 Note (verbatim, decisive for our provenance caution): "Despite the use of
  the word 'name' in 'named graph', the graph name is not required to denote
  the graph. It is merely syntactically paired with the graph. RDF does not
  place any formal restrictions on what resource the graph name may denote, nor
  on the relationship between that resource and the graph."
- §1.6: "There are many possible uses for RDF datasets. One such use is to hold
  snapshots of multiple RDF sources." — provenance is ONE use, not built-in
  meaning.
- §1.2: "Relations that involve more than two entities can only be indirectly
  expressed in RDF [SWBP-N-ARYRELATIONS]" — the spec itself cites the N-ary
  note (our NARY-01).
- §1.7 entailment (verbatim): "An RDF graph A entails another RDF graph B if
  every possible arrangement of the world that makes A true also makes B true.
  When A entails B, if the truth of A is presumed or demonstrated then the
  truth of B is established." — entailment is conditional on A's truth; it does
  not establish A's factual truth. Backs the Chapter 2 erratum wording and the
  Chapter 3/5/6 distinction.
