# R11-02: RDF 1.1 Concepts and Abstract Syntax

- **Canonical URL:** https://www.w3.org/TR/rdf11-concepts/
- **Status:** W3C Recommendation (2014-02-25)
- **Fetched:** 2026-08-25, HTTP 200
- **Used in:** Chapters 2, 3

## Key Points

- Defines the RDF abstract data model: triples (subject, predicate, object).
- Subject is IRI or blank node; predicate is IRI; object is IRI, blank node, or literal.
- An RDF graph is a set of triples.
- Introduces IRIs as the universal identifier mechanism.
- Literals have lexical form + datatype IRI (+ optional language tag).
- Blank nodes are existential variables with local scope.

## Semantic Contract for Chapter 1

- A triple is an *assertion* within the graph that contains it.
- The spec does not define "fact" vs "claim" — that distinction is an application-level epistemic policy.
- Reification (Section 3.7) allows stating propositions about triples without asserting them.
