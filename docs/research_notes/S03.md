# S03 — What is a Knowledge Graph? (Stanford CS520)

- **Source ID:** S03

- **Organization:** Stanford University

- **Used In:** Chapter 1

## Key Findings

- Defines KG as a directed labeled graph where labels have semantically defined meanings.
- Minimal formal definition: subset of N × L × N (nodes × labels × nodes).
- Does NOT require provenance, context, or validation as definitional prerequisites.
- Emphasizes that "Knowledge Graph" definitions vary across literature; no single universal definition exists.
