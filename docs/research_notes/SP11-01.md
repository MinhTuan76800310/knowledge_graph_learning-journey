# SP11-01: SPARQL 1.1 Overview

- **Canonical URL:** https://www.w3.org/TR/sparql11-overview/
- **Status:** W3C Recommendation (2013-03-21)
- **Fetched:** 2026-08-25, HTTP 200
- **Used in:** Chapter 2, Chapter 9

## Key Points

- Defines the SPARQL query language and protocol for RDF graph data
- Includes query, update, federated query, service description, and results formats
- Stable baseline for all SPARQL-based querying in this book
- SPARQL 1.2 Working Draft extends but does not replace this specification
