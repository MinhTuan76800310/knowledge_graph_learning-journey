# SH-01: Shapes Constraint Language (SHACL)

- **Canonical URL:** https://www.w3.org/TR/shacl/
- **Status:** W3C Recommendation (2017-07-20)
- **Fetched:** 2026-08-25, HTTP 200
- **Used in:** Chapters 5, 7, 10

## Key Points

- SHACL defines a language for validating RDF graphs against a set of conditions (shapes).
- Shapes are expressed as RDF graphs themselves.
- Validation produces a validation report indicating conformance or listing violations.
- SHACL is the correct mechanism for constraint checking and data validation in RDF systems.

## Semantic Contract

SHACL validation is fundamentally different from RDFS/OWL inference:
- RDFS/OWL: statement → entailment (adds information)
- SHACL: data + shapes → validation report (conforms / violation)

Do not confuse SHACL constraints with RDFS domain/range semantics. See R11-03 for the distinction.

## Stability

This is the stable W3C Recommendation baseline for the curriculum. SHACL 1.2 (SH-02) is a Working Draft that extends but does not replace this specification.
