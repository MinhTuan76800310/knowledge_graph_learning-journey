# WD-02: Wikidata — Help:Qualifiers

- **Canonical URL:** https://www.wikidata.org/wiki/Help:Qualifiers
- **Status:** Official Wikidata help page (living document)
- **Fetched:** 2026-08-25, HTTP 200
- **Used in:** Chapter 3 (qualifiers as context)

## Key Points

- Qualifiers "allow statements to be expanded on, annotated, or contextualized
  beyond what can be expressed in just a simple property–value pair."
- A qualifier is itself a property–value pair attached to a statement.
- Documented qualifier roles:
  - modify what an item means ("France — excluding Adélie Land" → scope),
  - indicate how a value was determined ("population — method: estimation"),
  - constrain the validity of a value ("population — as of 2011" → time),
  - offer further details not otherwise expressible.
- Guidance: a statement should still provide useful data WITHOUT its qualifier;
  the qualifier adds information, it does not replace the core claim.

## Semantic Contract for Our Chapter 3

- Qualifier roles map directly onto our context axes (scope, method, time).
- The "statement remains useful without the qualifier" rule is a clean way to
  teach that context refines interpretation rather than creating truth.
