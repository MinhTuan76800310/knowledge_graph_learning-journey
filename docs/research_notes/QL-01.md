# QL-01: Ontop Virtual Knowledge Graph System

- **URL:** https://ontop-vkg.org/guide/
- **Status:** FETCHED_AND_VERIFIED
- **Used in:** Chapter 4 (English edition - real-world enrichment)
- **Document status:** Ontop documentation (stable)

## What this source establishes for Ch4
A production OBDA/virtual-KG system that translates SPARQL into SQL over relational sources and explicitly supports RDFS and OWL 2 QL via R2RML mappings - a concrete instance of QL's purpose (query answering over very large instance data by rewriting into SQL).

## Safe simplifications
Citing Ontop as an OWL 2 QL OBDA/VKG system is safe.

## Dangerous simplifications / limits
Do not imply Ontop does full DL classification; QL is about query rewriting, not subsumption over huge TBoxes.
