# RLP-01: RDFox

- **URL:** https://www.cs.ox.ac.uk/isg/tools/RDFox/
- **Status:** FETCHED_AND_VERIFIED
- **Used in:** Chapter 4 (English edition - real-world enrichment)
- **Document status:** Oxford Semantic Technologies (stable)

## What this source establishes for Ch4
An in-memory RDF store supporting RDF, RDFS, OWL 2 RL and Datalog with incremental, shared-memory parallel forward-chaining materialization - a production demonstration that RL's syntax is chosen so reasoning runs on scalable rule/Datalog engines over RDF.

## Safe simplifications
Citing RDFox as an OWL 2 RL / Datalog forward-chaining engine is safe.

## Dangerous simplifications / limits
Do not claim RL completeness on arbitrary RDF graphs; the profile's own limitation applies.
