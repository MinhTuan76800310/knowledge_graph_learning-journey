# R11-01: RDF 1.1 Primer

- **Canonical URL:** https://www.w3.org/TR/rdf11-primer/
- **Status:** W3C Recommendation (2014-02-25)
- **Fetched:** 2026-08-25, HTTP 200

## Key Points

- Introductory document for RDF 1.1; explains triples, IRIs, literals, blank nodes, and named graphs.
- Defines RDF as a directed labeled graph where edges are predicates labeled with IRIs.
- Does not define inference semantics; those belong to RDFS/OWL.
