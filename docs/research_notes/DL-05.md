# DL-05: Protege ontology editor

- **URL:** https://protegeproject.github.io/protege/
- **Status:** FETCHED_AND_VERIFIED
- **Used in:** Chapter 4 (English edition - real-world enrichment)
- **Document status:** IEEE Intelligent Systems 16(2) 2001 + official docs

## What this source establishes for Ch4
The practical editor where Ch4 class expressions (intersection/union/complement, existential/universal restrictions, cardinality) and axioms are authored; it drives the DL reasoners above. Grounds the 'how you actually write these axioms' thread.

## Safe simplifications
Citing it as the standard open-source OWL editor is safe.

## Dangerous simplifications / limits
The 2001 paper describes Protege-2000; the OWL 2 editor is Protege 5.x (official docs). Do not attribute OWL 2 features to the 2001 paper.
