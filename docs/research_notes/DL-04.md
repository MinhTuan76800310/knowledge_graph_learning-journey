# DL-04: Konclude: System Description

- **URL:** https://doi.org/10.1016/j.websem.2014.06.003
- **Status:** FETCHED_AND_VERIFIED
- **Used in:** Chapter 4 (English edition - real-world enrichment)
- **Document status:** Journal of Web Semantics (Elsevier, 2014)

## What this source establishes for Ch4
A state-of-the-art OWL 2 DL reasoner demonstrating that full-expressivity entailment and classification are a solved engineering problem - the 'full OWL 2 DL' pole of the expressivity-vs-efficiency trade-off that Ch4's profiles section contrasts against ELK.

## Safe simplifications
Presenting it as a high-performance OWL 2 DL reasoner is safe.

## Dangerous simplifications / limits
Do not imply it is faster than EL reasoners on EL ontologies; it targets full DL, a different complexity class.
