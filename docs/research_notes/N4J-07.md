## Key Points

- The Neo4j Python Driver is the official library for interacting with Neo4j via Python.
- Connection uses the **Bolt protocol** (default port 7687).
- Driver creation pattern:
  ```python
  from neo4j import GraphDatabase
  with GraphDatabase.driver(URI, auth=AUTH) as driver:
      driver.verify_connectivity()
  ```
- Query execution via `driver.execute_query()`:
  ```python
  summary = driver.execute_query(
      "CREATE (a:Person {name: $name})", name="Alice"
  )
  ```
- Driver version 6 covers Neo4j 4.4, 5.x, and AuraDB.
- LTS releases (4.4, 5.26+) receive extended support.

## Compatibility

- neo4j driver 6.x is compatible with Neo4j server 5.x (and 4.4, 2025.x+).
- This project uses neo4j driver 6.2.0 with Neo4j server 5.26 LTS.
