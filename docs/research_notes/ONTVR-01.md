# ONTVR-01: Ontology Versioning on the Semantic Web

- **Primary reference:** Klein, M., Fensel, D. (2001). "Ontology versioning on the Semantic Web." *Proceedings of the International Semantic Web Working Symposium (SWWS) 2001*, pp. 75–91.
- **Status:** FETCHED_AND_VERIFIED (DBLP metadata verified, 2026-08-31)
- **Used in:** Chapter 10

## Key Points

- Defines ontology versioning: differences between ontology versions, version identification, and maintaining links across versions.
- Introduces version graphs and the distinction between backward compatibility and incompatibility.

## Semantic Contract

- Versioning is a necessary condition for a living system (supersession, audit).
- The book uses this to support the versioning aspect of KGOps and supersession management.
