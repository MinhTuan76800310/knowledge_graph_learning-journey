# GQL-02: Neo4j Cypher — GQL Conformance

- **Canonical URL:** https://neo4j.com/docs/cypher-manual/current/appendix/gql-conformance/
- **Status:** Official documentation
- **Fetched:** 2026-08-25, HTTP 200

## Key Points

- Neo4j states that Cypher accommodates "most mandatory GQL features and a
  substantial portion of its optional ones."
- Cypher supports all mandatory GQL property types plus additional optional types.
- Some mandatory GQL features remain unsupported in Cypher.
- Cypher is aligned with GQL but is NOT identical to GQL.

## Semantic Contract for Chapter 2

- When teaching Cypher, include a callout:
  "GQL = ISO graph query language standard (ISO/IEC 39075:2024).
   Cypher has significant GQL alignment/conformance but is not identical to GQL."
- Do not equate Cypher with GQL.
- Do not present Cypher as a universal graph query standard.
