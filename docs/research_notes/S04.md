## Key Points

- Discusses RDF as a framework for representing information on the web.
- Describes the property graph model: nodes, relationships, and properties,
  where edges can have properties without requiring IRIs or blank nodes.
- Notes representation trade-offs: graph models favor rich relationships;
  property graphs simplify traversals compared to relational models.
- RDF uses IRIs and blank nodes; property graphs use internal identifiers.
