## What this source establishes for Ch4
A large OBO Foundry biomedical ontology built from a small set of typed relations (is_a, part_of, occurs_in) over classes - the class-hierarchy/subclass reasoning EL reasoners compute. Grounds classes-as-sets and EL-style terminologies in a real annotation resource.

## Safe simplifications
Presenting GO as a large OBO Foundry terminology suited to EL-style reasoning is safe.

## Dangerous simplifications / limits
The GO page does not literally state 'OWL 2 EL'; do not overclaim the profile label - describe it as an OBO class-rich ontology.
