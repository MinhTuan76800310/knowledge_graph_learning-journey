# DEFLOGIC-01: A Logic for Default Reasoning (Reiter)

- **Status:** FETCHED_AND_VERIFIED (verified via ScienceDirect record)

## What this source establishes for Ch5
Foundational non-monotonic default logic: conclusions that hold "by default" and are retracted
when contradicted (the classic bird/penguin example). The chapter uses it in §5.2 to draw the
boundary of monotonicity — forward chaining never retracts, whereas default reasoning does.

## Safe simplifications
Citing Reiter 1980 as the canonical default-logic reference is safe.

## Dangerous simplifications / limits
Mentioned only to mark the boundary of the monotonic regime; the chapter does not teach default
logic. Do not imply the KG inference pipeline is non-monotonic — RDFS/OWL RL/RIF-Core are all
monotonic.
