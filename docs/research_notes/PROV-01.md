# PROV-01: PROV-O: The PROV Ontology

- **Canonical URL:** https://www.w3.org/TR/prov-o/
- **Status:** W3C Recommendation (2013-04-30)
- **Fetched:** 2026-08-25, HTTP 200
- **Used in:** Chapters 6, 10

## Key Points

- Defines an OWL ontology for representing provenance information.
- Core classes: Entity, Activity, Agent.
- Core properties: wasGeneratedBy, wasAttributedTo, wasDerivedFrom, used, wasAssociatedWith.
- Provides a standard vocabulary for expressing how data was produced, by whom, and when.

## Semantic Contract

PROV-O assertions describe the lineage and responsibility of entities. They do not validate data correctness; they record derivation history. Provenance supports trust evaluation but does not itself constitute validation.
