# N4J-08: Neo4j Docker Documentation

- **Canonical URL:** https://neo4j.com/docs/operations-manual/current/docker/
- **Status:** Official documentation
- **Fetched:** 2026-08-25, HTTP 200

## Key Points

- Neo4j is available as a Docker image.
- Three documented product versions:
  - **2026.07** (Current) — calendar versioning
  - **5.26** (LTS) — long-term support
  - **4.4** — older LTS
- Neo4j transitioned from traditional 5.x numbering to calendar-based
  versioning (2025.x, 2026.x) for newer releases.
- The 5.26 line remains the LTS release with extended support.
- Docker Hub tags include:
  - `5.26.30-community` (exact patch, community edition)
  - `5.26-community` (floating minor, community edition)
  - `5.26.30` (exact patch, default edition)
- Note: `5.26.0-community` does NOT exist as a Docker Hub tag.
  The earliest visible 5.26.x tag is `5.26.30-community`.

## Decision for This Project

- Pin to `neo4j:5.26.30-community` for reproducibility.
- See `docs/decisions/ADR-002-neo4j-version.md`.
