## Key Points — Schema

- Graphs allow postponing schema definition; schemata prescribe high-level
  structure and/or semantics the graph follows or should follow.
- Semantic schema: classes, properties, sub-class, sub-property, domain, range
  (RDFS as the prominent standard; OWL for deeper semantics, deferred to their
  Chapter 4).
- Validating schema: constraints data must satisfy (distinct from semantic schema).
- Emergent schema: structure extracted from the data itself (quotient graphs,
  bisimulation) — schema can be bottom-up.
- OWA vs CWA vs LCWA: absence of an edge does not mean the relation does not hold.

## Key Points — Identity

- Ambiguous local names cause naming clashes when graphs merge (their
  "Santiago" example: Chile vs Cuba vs Compostela vs a band).
- Persistent identifiers (PIDs): DOI, ORCID, ISBN, Alpha-2 codes.
- IRIs vs URLs: Wikidata webpage URL (wikidata.org/wiki/Q2887) vs entity IRI
  (wikidata.org/entity/Q2887); namespaces wd:/wdt:.
- IRIs alone do NOT ground identity: two namespaces can mint different IRIs for
  the same entity; merging then yields two disconnected nodes.
- owl:sameAs identity links; transitivity via a shared hub (both link to
  wd:Q2887 ⇒ infer mutual sameAs). Semantics deferred to their Chapter 4;
  computation of identity links deferred to their Chapter 8.
- Lexicalisation: rdfs:label, skos:altLabel, rdfs:comment; identifiers carry no
  formal semantic significance; Wikidata Q-ids are language-neutral and survive
  renaming (Q1050 Swaziland→Eswatini).
- Existential nodes (blank nodes) for "something exists but is unidentified".

## Key Points — Context

- Context = "scope of truth": the context in which data are held true
  (temporal, geographic, provenance; combinable).
- Direct representation: context as ordinary data (TIME ontology, PROV).
- Reification: RDF reification, n-ary relations pattern, singleton properties.
  IMPORTANT: "a reified edge does not assert the edge it reifies".
- Higher-arity: named graph (most flexible — context on many edges at once),
  property-graph edge properties, RDF* (least flexible without edge ids —
  cannot pair multiple value groups, e.g. two presidential terms).
- Annotations (temporal/fuzzy/semiring) and contextual repositories exist but
  are research-level; out of scope for our Chapter 3 beyond mention.
