# ONTEVOL-01: Ontology Evolution — Not the Same as Schema Evolution

- **Primary reference:** Noy, N.F., Klein, M. (2004). "Ontology Evolution: Not the Same as Schema Evolution." *Knowledge and Information Systems* 6(4):428–440.
- **DOI:** 10.1007/S10115-003-0137-2

## Key Points

- Argues ontology evolution differs fundamentally from database schema evolution because ontologies have instance data, shared mappings, and evolving domain understanding.
- Introduces dimensions of ontology evolution (version identification, change representation, propagation).

## Semantic Contract

- The book uses this to distinguish schema migration (Ch3/Ch4) from full KG lifecycle change.
- Supports the argument that ontology changes require governed operations.
