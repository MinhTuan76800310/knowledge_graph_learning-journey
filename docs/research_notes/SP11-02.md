# SP11-02: SPARQL 1.1 Query Language

- **Status:** W3C Recommendation (2013-03-21)

## Key Points

- Defines the full SPARQL 1.1 query syntax and semantics.
- Covers SELECT, CONSTRUCT, ASK, DESCRIBE query forms.
- Defines basic graph patterns, optional matching, unions, filters, and aggregation.
- Stable baseline for all SPARQL querying in this book.
