# HIDDENTECH-01: Hidden Technical Debt in Machine Learning Systems

- **Primary reference:** Sculley, D., Holt, G., Golovin, D., Davydov, E., Phillips, T., Ebner, D., Chaudhary, V., Young, M., Crespo, J.-F., Dennison, D. (2015). "Hidden Technical Debt in Machine Learning Systems." *NIPS 2015*.
- **URL:** https://proceedings.neurips.cc/paper/2015/hash/86df7dcfd896fcaf2674f757a2463eba-Abstract.html
- **Status:** FETCHED_AND_VERIFIED (DBLP metadata verified, 2026-08-31)
- **Used in:** Chapter 10

## Key Points

- Classic paper on ML system maintenance: feedback loops, configuration debt, data dependencies, and the erosion of boundaries between ML and software.
- Introduces the concept of "debt" in ML systems — measuring the cost of accumulated shortcuts.

## Semantic Contract

- The book's "knowledge debt" concept is inspired by the "technical debt" framing, applied to the epistemic domain.
- Feedback loops (Sculley §5) are directly relevant to the book's feedback loop safety analysis.
- MUST NOT: claim ML debt = knowledge debt; the book defines its own epistemic version.
