# DL-03: HermiT / Hypertableau Reasoning for Description Logics

- **URL:** https://www.cs.ox.ac.uk/isg/tools/HermiT/
- **Status:** FETCHED_AND_VERIFIED
- **Used in:** Chapter 4 (English edition - real-world enrichment)
- **Document status:** JAIR 36 (2009) + Oxford ISG tool page

## What this source establishes for Ch4
A production OWL 2 DL reasoner using a hypertableau calculus; the official page states it uses Direct Semantics and passes all OWL 2 direct-semantics conformance tests. Grounds the Ch4 Direct-vs-RDF-Based semantics subsection and the consistency/satisfiability/entailment distinction.

## Safe simplifications
Citing it as a Direct-Semantics-conformant OWL 2 DL reasoner is safe.

## Dangerous simplifications / limits
Do not overstate conformance beyond what the tool page states; the JAIR paper is the algorithm, the tool page is the conformance claim.
