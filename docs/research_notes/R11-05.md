# R11-05: RDF 1.1 Turtle

- **Canonical URL:** https://www.w3.org/TR/turtle/
- **Status:** W3C Recommendation (2014-02-25)
- **Fetched:** 2026-08-25, HTTP 200

## Key Points

- Defines a textual syntax for RDF called Turtle that allows an RDF graph to be
  completely written in a compact and natural text form, with abbreviations for
  common usage patterns and datatypes.
- Turtle is a **concrete syntax** for RDF, not the data model itself. The abstract
  data model is defined in RDF 1.1 Concepts [R11-02].
- Key syntactic features:
  - `@prefix` declarations for namespace abbreviation
  - Prefixed names (e.g., `ex:Hanoi`) as shorthand for full IRIs
  - Predicate-object lists using `;` to share a subject
  - Object lists using `,` to share subject and predicate
  - Literals with optional `^^datatype` or `@lang` suffix
  - Numeric and boolean literal shorthands
- The Turtle grammar is a subset of the SPARQL 1.1 grammar.
- Two syntactically different Turtle documents can produce identical RDF graphs.

## Semantic Contract for Chapter 2

- Turtle is ONE serialization of the RDF abstract model.
- Comparing RDF content must be done at the graph level (parsed triples),
  not at the Turtle string level.
- Prefix declarations are syntactic sugar; they do not change underlying IRIs.
