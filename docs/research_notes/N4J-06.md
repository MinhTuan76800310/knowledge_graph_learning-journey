## Key Points

- Cypher is Neo4j's declarative query language.
- Core clauses:
  - `MATCH` — pattern matching against the graph
  - `WHERE` — filtering conditions
  - `RETURN` — project results
  - `CREATE` — create nodes and relationships
  - `MERGE` — match or create
- Relationship pattern syntax: `(a)-[r:TYPE]->(b)`
  - Parentheses for nodes, square brackets for relationships
  - Arrow indicates direction
  - `:TYPE` specifies relationship type
- Cypher uses ASCII-art-style graph patterns.

## GQL Relationship

- Cypher has significant alignment with ISO GQL but is not identical.
- See GQL-02 for detailed conformance information.

## Semantic Contract for Chapter 2

- Cypher is specific to Neo4j (and compatible implementations).
- Do not equate Cypher with GQL.
- Pattern matching in Cypher operates on the property graph model,
  which differs from SPARQL's RDF graph pattern matching.
