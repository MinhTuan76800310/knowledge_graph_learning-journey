## Key Findings

- SHACL 1.2 Core exists as a Working Draft at the correct URL `shacl12-core` (not `shacl-12-core`).
- Previous Phase 1 research incorrectly concluded SHACL 1.2 did not exist due to using the wrong URL path.
- This is an emerging standard; the stable baseline for curriculum remains SH-01 (SHACL 1.0, W3C Recommendation 2017-07-20).
- SHACL 1.2 extends SHACL Core with new constraint components and refinements but maintains backward compatibility with SHACL 1.0 shapes.

## Semantic Contract

SHACL 1.2 Core defines validation constraints that check data against shapes. Unlike RDFS domain/range (which produce entailments), SHACL constraints produce conformance results (conforms/violation). This distinction is critical for Chapter 5.
