# R12-01: RDF 1.2 Concepts and Abstract Data Model

- **Source ID**: R12-01
- **Canonical URL**: https://www.w3.org/TR/rdf12-concepts/
- **Status**: W3C Candidate Recommendation Snapshot
- **Publication Date**: 2026-04-07
- **Stability**: EMERGING
- **Used In**: Chapters 2, 3, 6

## Key Findings

- Successor to RDF 1.1 with updated abstract data model.
- Introduces refinements to triple terms and reification semantics.
- Maintains backward compatibility with RDF 1.1 graphs.
- Not yet a W3C Recommendation; treat as emerging standard.

## Semantic Contract

RDF 1.2 extends the RDF 1.1 data model. Core triple structure (subject, predicate, object) remains unchanged. New features around triple terms are experimental and should not be taught as stable semantics in Chapter 1.
